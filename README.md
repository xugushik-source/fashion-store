# FASHION — локальный прототип
Этапы 1–2: главная, три визуальных мира, демонстрационный каталог, страницы товаров, варианты, фильтры, избранное, готовый образ и корзина. Реальные продажи, поставщики, база и админка не реализованы. Визуальная приёмка ограничена EPERM среды.

## Открытие
Без установки: откройте `index.html` в браузере (файловый режим поддерживается, скрипт классический).
С Node.js 22+:
```
cd /workspace/fashion
npm start
```
Открыть http://localhost:3000. Можно задать PORT. Зависимости устанавливать не нужно. `npm run check` проверяет синтаксис и логику подборок/локальные изображения. Отдельной сборки нет.

В текущей управляемой среде предпросмотр остановился с `listen EPERM`; рабочий HTTP URL не подтверждён. Проверка визуального вида и iPhone остаётся обязательной для завершения приёмки этапа 1.

## Структура
`index.html` — главная; `style.css` — адаптивный вид и motion; `app.js` — единый демокаталог, настройки и переключение подборок; `shop-core.js` — правила фильтрации/вариантов/корзины; `shop.js` — страницы товаров, формы и сохранение в браузере; `server.mjs` — локальный статический сервер; `assets/` — фотографии; `tests/` — проверки. ТЗ и продолжение: SPEC.md, PLANS.md, PROGRESS.md, AGENTS.md.
Деньги в демоданных — целые тетри. `settings` в app.js — временная конфигурация до защищённых настроек этапа 3; номер WhatsApp пустой намеренно. Контакт не вымышленный, отправка отключена. Редактируемая админка и полный RU/KA/HY — последующие этапы.

## Фото и шрифты
Локальные редакционные фото Unsplash, идентификаторы в ASSETS.md. Изображения иллюстративны, не представляют конкретный товар. Перед коммерческим использованием проверить права и заменить при необходимости. Google Fonts загружается опционально; без сети работают Georgia/Arial/system fallbacks. Грузинская и армянская типографика будет проверена на этапе 7.

## Проверка этапа 2 вручную
1. Открыть каталог, выбрать категорию; совместить поиск, сегмент, размер, цвет, доступность и границы цены. Проверить пустую выборку и сброс.
2. Открыть карточку, выбрать размер/цвет; недоступный вариант нельзя добавить. Увеличить фото, закрыть кнопкой или Escape.
3. Добавить один вариант дважды: одна строка, количество 2. Другой цвет — отдельная строка. Проверить увеличение/уменьшение/удаление и итог в GEL.
4. Добавить в избранное, открыть избранное, удалить; перезагрузить и проверить сохранение.
5. «Собрать тестовый образ»: выбрать варианты всех вещей, добавить комплект. При превышении лимита ни одна часть комплекта не добавляется.
6. Перезагрузить: корзина восстанавливается. Если localStorage запрещён, интерфейс работает в памяти и сообщает об ограничении.
7. Проверить 390px/desktop, клавиатуру, Safari и reduced-motion. Эти браузерные проверки в текущей среде не выполнены.

Данные сохраняются только в этом браузере под ключами `fashion-demo-v1-cart` / `fashion-demo-v1-favorites`. Здесь нет серверного заказа или резерва. Корзина не содержит персональных данных. Характеристики, остатки, сроки и цены тестовые. Отдельной фотогалереи реального товара пока нет: одно иллюстративное фото на модель с увеличением. Все карточки формируются из общего массива; замена реальными товарами и хранение в БД — этап 3.
