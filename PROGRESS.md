# Этап 3 — 26.11.2026
По прямому поручению пользователя выполнен код следующего функционального этапа — постоянная БД и админка каталога. Визуальная приёмка этапов 1–3 остаётся открытой из-за ранее подтверждённого listen EPERM; неподтверждённые HTTP/browser результаты не заявляются. Этап 4 не начинался.

## Реализовано
SQLite (встроенный node:sqlite, Node 24+), таблицы товаров/вариантов/поставщиков/пользователей/метаданных, одноразовый seed существующих 6 демокарточек. Сохранение товаров и вариантов транзакционно, контроль версии против потерянных обновлений, деньги в целых тетри, валидация размеров/остатков/статусов/медиа. Данные и uploads исключены из Git.
Публичный API отдаёт только публичные поля активных демотоваров. Витрина при HTTP загружается из БД, при ошибке не подменяет её seed. Имена/описания экранируются при HTML-рендере. Фото хранятся локально: загрузка с проверкой размера/сигнатуры, SVG запрещён, галерея поддерживает несколько фото.
Админка /admin: вход/выход, товары, размеры/цвета, цены/остатки, фото, скрытие товара, подборки; владельцу доступны поставщики, контакты/условия/регион/перевозка/импорт/закупочные цены. Редактору коммерческие поля не отдаются, попытка их изменения игнорируется сервером. API защищён входом, проверкой Origin для изменений, HttpOnly/SameSite сессиями, лимитом попыток. Пароли scrypt; нет пароля по умолчанию. Интерактивное создание пользователя со скрытым вводом и отдельная stdin-команда; секреты не добавлены в код.
SQLite online backup и инструкция восстановления/сохранения фотографий. Само внешнее хранилище/расписание не подключено.

## Реальные проверки

Новый интеграционный тест использует настоящую временную SQLite и серверный Request/Response handler без порта: создание/редактирование → публичный каталог; запрет анонимного доступа; owner/editor; исключение supplierId/cost/контактов из витрины; CSRF; отказ отрицательной цены/пути к БД/SVG; конфликт версии; logout; повторное открытие БД; чтение online backup. Предыдущие 7 проверок также прошли.
`node manage.mjs` успешно создал локальную игнорируемую БД и загрузил 6 демотоваров. Пользователь админки не создан автоматически: установить свой пароль командой `npm run user`.
HTTP-сервер/браузер/iPhone в этом запуске не проверены. Известную системную ошибку порта не повторяли без изменений инфраструктуры. Тесты DOM не заменяют визуальную проверку.
